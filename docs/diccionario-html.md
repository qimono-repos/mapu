
# Términos Técnicos de HTML (Inglés-Español)

A continuación, se presenta un diccionario de términos técnicos comunes relacionados con HTML, utilizados en el desarrollo frontend, con sus traducciones y explicaciones breves en español. Este formato es compatible con Google Docs para facilitar su edición.

**HTML** (HTML): Lenguaje de Marcado de Hipertexto (HyperText Markup Language). Es el lenguaje estándar para estructurar contenido en la web.

**Tag** (Etiqueta): Elemento básico de HTML que define la estructura o el significado del contenido, como `<p>` para párrafos.

**Element** (Elemento): Combinación de una etiqueta de apertura, contenido y una etiqueta de cierre, por ejemplo, `<p>Texto</p>`.

**Attribute** (Atributo): Propiedad adicional dentro de una etiqueta que modifica su comportamiento o apariencia, como `class` o `id`.

**Class** (Clase): Atributo que asigna un nombre a un elemento para aplicar estilos CSS o manipularlo con JavaScript.

**ID** (Identificador): Atributo único para identificar un elemento específico en una página.

**Div** (Div): Etiqueta `<div>` que actúa como contenedor para agrupar otros elementos y aplicar estilos o comportamientos.

**Span** (Span): Etiqueta `<span>` para aplicar estilos o manipulaciones a una porción específica de texto dentro de un elemento.

**Semantic HTML** (HTML Semántico): Uso de etiquetas que describen el significado del contenido, como `<header>`, `<article>` o `<footer>`.

**Head** (Cabeza): Etiqueta `<head>` que contiene metadatos, enlaces a recursos (como CSS) y el título de la página.

**Body** (Cuerpo): Etiqueta `<body>` que contiene el contenido visible de la página web.

**Anchor** (Ancla): Etiqueta `<a>` utilizada para crear hipervínculos a otras páginas o recursos.

**Src** (Fuente): Atributo que especifica la ubicación de un recurso, como una imagen en `<img src="imagen.jpg">`.

**Alt** (Alternativo): Atributo de `<img>` que proporciona un texto descriptivo para accesibilidad o si la imagen no carga.

**Meta** (Meta): Etiqueta `<meta>` que define metadatos, como la codificación de caracteres o la descripción de la página.

**Inline** (En línea): Elementos que no crean un salto de línea, como `<span>` o `<a>`.

**Block** (Bloque): Elementos que ocupan todo el ancho disponible y crean un salto de línea, como `<div>` o `<p>`.

**Doctype** (Doctype): Declaración `<!DOCTYPE html>` al inicio de un documento HTML para indicar la versión del lenguaje.

**Charset** (Conjunto de caracteres): Atributo en `<meta>` que define la codificación de caracteres, como `UTF-8`.

**Form** (Formulario): Etiqueta `<form>` para crear interfaces interactivas que recopilan datos del usuario.

**Input** (Entrada): Etiqueta `<input>` para campos de entrada de datos en formularios, como texto o botones.

**Label** (Etiqueta): Etiqueta `<label>` que asocia un texto descriptivo a un campo de formulario para mejorar la accesibilidad.

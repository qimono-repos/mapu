Diccionario de Términos Técnicos de CSS (Inglés-Español)
A continuación, se presenta un diccionario de términos técnicos comunes relacionados con CSS (Cascading Style Sheets), utilizados en el desarrollo frontend, con sus traducciones y explicaciones breves en español. Este formato es compatible con Google Docs para facilitar su edición.
CSS (CSS): Hojas de Estilo en Cascada (Cascading Style Sheets). Lenguaje utilizado para definir la presentación y el diseño de documentos HTML.
Selector (Selector): Patrón que identifica los elementos HTML a los que se aplicarán estilos, como p para párrafos o .clase para clases.
Property (Propiedad): Característica de estilo que se define en una regla CSS, como color o font-size.
Value (Valor): Configuración asignada a una propiedad CSS, como blue para color o 16px para font-size.
Rule (Regla): Combinación de un selector y un bloque de declaraciones que especifican estilos, por ejemplo, p { color: blue; }.
Declaration (Declaración): Par formado por una propiedad y un valor dentro de una regla CSS, como color: blue.
Class Selector (Selector de Clase): Selector que apunta a elementos con un atributo class, usando la notación .nombre-clase.
ID Selector (Selector de Identificador): Selector que apunta a un elemento con un atributo id único, usando la notación #nombre-id.
Pseudo-class (Pseudo-clase): Estado especial de un elemento, como :hover para cuando el cursor pasa sobre él.
Pseudo-element (Pseudo-elemento): Parte específica de un elemento, como ::before o ::after, usada para estilizar contenido generado.
Box Model (Modelo de Caja): Concepto que describe los elementos HTML como cajas con contenido, padding, bordes y márgenes.
Padding (Relleno): Espacio interno entre el contenido de un elemento y su borde.
Margin (Margen): Espacio externo alrededor de un elemento, fuera de su borde.
Border (Borde): Línea que rodea el padding y el contenido de un elemento, definida por propiedades como border-width.
Display (Display): Propiedad que controla cómo se muestra un elemento, como block, inline o flex.
Flexbox (Flexbox): Modelo de diseño que organiza elementos en un contenedor flexible, usando propiedades como display: flex.
Grid (Cuadrícula): Modelo de diseño bidimensional para organizar contenido en filas y columnas, usando display: grid.
Position (Posición): Propiedad que define el método de posicionamiento de un elemento, como static, relative, absolute o fixed.
Z-index (Índice Z): Propiedad que controla el orden de apilamiento de elementos en el eje Z (profundidad).
Media Query (Consulta de Medios): Técnica para aplicar estilos según las características del dispositivo, como @media (max-width: 600px).
Transition (Transición): Propiedad que anima cambios suaves en los valores de otras propiedades, como transition: opacity 0.3s.
Transform (Transformación): Propiedad que aplica transformaciones como rotar, escalar o trasladar un elemento, por ejemplo, transform: rotate(45deg).
Opacity (Opacidad): Propiedad que controla la transparencia de un elemento, con valores entre 0 (transparente) y 1 (opaco).
Font-family (Familia de Fuentes): Propiedad que especifica la fuente tipográfica, como font-family: Arial, sans-serif.
Responsive Design (Diseño Responsivo): Enfoque de diseño que adapta la interfaz a diferentes tamaños de pantalla usando media queries, flexbox, grid, etc.
